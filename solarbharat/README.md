# SolarBharat (web)

Phase 1 MVP: Vite + React + TypeScript + Tailwind. Run locally:

```bash
npm install
npm run dev
```

Production build: `npm run build`. Deploy the `solarbharat` directory to Vercel (`vercel.json` includes SPA rewrites).

Repository overview and product plan: see the root [`README.md`](../README.md) and [`docs/SOLAR_BHARAT_PRODUCT_PLAN.md`](../docs/SOLAR_BHARAT_PRODUCT_PLAN.md).
